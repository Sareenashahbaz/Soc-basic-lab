# SOC Fundamentals Lab – Linux Network & Log Analysis

## 1. Title
SOC Fundamentals Lab – Linux Network & Log Analysis

---

## 2. Objective

This lab focuses on building foundational SOC (Security Operations Center) skills, including:

- Network traffic monitoring and analysis  
- Linux system log inspection  
- Developing a basic threat detection mindset  

---

## 3. Tools & Techniques Used

### Network Monitoring
- Wireshark for packet capture and traffic inspection  
- Observation of protocols such as TCP and DNS  

### Network Scanning
- Nmap for host discovery and port scanning  

### Log Analysis
- `journalctl` for reviewing system logs  
- Identification of warnings and authentication events  

---

## 4. Summary of Activities

- Captured and analyzed live network traffic using Wireshark  
- Performed basic network scanning using Nmap  
- Inspected Linux system logs using `journalctl`  
- Observed system behavior and potential anomalies  

---

## 5. Key Findings

- DNS and TCP traffic patterns were observed during analysis  
- System logs contained service-level warnings  
- Authentication failure events were detected in local logs  
- No confirmed external attack, but suspicious patterns were noted for learning purposes  

---

## 6. Conclusion

This lab successfully demonstrated foundational SOC skills, including network monitoring, packet inspection, and Linux log analysis. It helped build initial understanding of how security analysts identify and interpret system and network-level events.
